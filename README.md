# Kinoticket-System
---
Das Kinoticket-System ist eine modulare Konsolenanwendung in Python zur Erfassung von Kinoticket Bestellungen, automatisierten Rabattkalkulation und Belegausstellung für Kinobetriebe
---
### Problemstellung 
In kleineren Kinos werden Ticketverkäufe, Kategorie-Ermässigungen, Kinder, Studenten und Gruppenrabatte häufig manuell berechnet. Dies führt zu Kassenverzägerungen, Rundungsfehlern und fehlender Übersicht beim täglichen Kassensturz
